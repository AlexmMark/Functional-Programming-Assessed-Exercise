# connect4

Submission When you are ready to submit, please create a ZIP file containing only your Game.hs and Render.hs files, and a status.txt file detailing the exercises you have attempted.
Please submit a single zip file to the Moodle submission box, where the name of the file corresponds to your student ID (for example, 2600000F.zip). Your submission will be assessed according to the usual University policies on lateness and plagiarism. Remember that this is individual work and you must not share code with others.
Important: We expect your code to compile. Submissions that do not compile because of syntax or type errors will be capped at 15 marks.

* Setup.hs, package.yaml, and stack.yaml are project files used by Stack; you should not edit
these.
* app/Main.hs is the main entry point of the program. It parses in the command line arguments and either runs the text-based or graphical UI.
* src/Game.hs(⋆)containsthegamelogic(includingboardrepresentationandwin-checkingfunctions).
* src/Render.hs (⋆) contains the code to render the board and allow user interaction.
